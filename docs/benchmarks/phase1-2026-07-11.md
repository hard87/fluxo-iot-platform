# Phase 1 benchmark — 2026-07-11

Ambiente isolado por `scripts/benchmark/docker-compose.phase1.yml`: Windows host, Docker 29.4.0,
PostgreSQL 16 Alpine, Mosquitto 2, .NET 10.0.6. Containers sem limites explícitos; host com
15,1 GiB disponíveis aos containers. Latência é **processing latency monotônica no Worker**,
do início do processamento ao resultado após commit; não é latência end-to-end.

Entre perfis, tabelas de telemetria foram truncadas e o Worker reiniciado para limpar cache.
Devices/credenciais foram preservados. O dense exige catálogo das 32 chaves pré-semeado, pois
32 discoveries novas em uma mensagem excedem corretamente o guardrail de 20/device/hora.
